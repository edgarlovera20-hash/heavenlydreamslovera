# Admin Web

App central de Heavenly Dreams para gerencia, administracion, supervision, finanzas, reportes, usuarios, validaciones, automatizaciones e integraciones.

Esta carpeta recibira la app principal que hoy vive en `src/App.tsx` y `src/main.tsx`.

## Responsabilidad

- Dashboard enterprise
- Usuarios y roles
- Ventas y clientes globales
- Validaciones
- Finanzas
- Nomina completa
- Reportes
- Automatizaciones IA
- Integraciones
- Configuracion

No debe contener modulos internos exclusivos de campo movil.
