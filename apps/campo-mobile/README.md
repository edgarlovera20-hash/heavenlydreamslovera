# Campo Mobile

App movil de Heavenly Dreams para fuerza de venta, asesores, reclutadores y operacion en campo.

Esta carpeta recibira la app movil que hoy vive en `src/mobile` y que se carga desde `mobile.html`.

## Responsabilidad

- Inicio del asesor
- Nueva venta
- Captura de cliente
- Carga de documentos
- Evidencias multimedia
- GPS
- OCR movil
- Folios propios
- Seguimiento
- Chats
- Nomina personal
- Modo offline
- Sincronizacion

No debe contener administracion global, finanzas enterprise ni configuracion sensible del sistema.
